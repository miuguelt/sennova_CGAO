# Especificación visual para revisión futura

Contexto: investigadores que construyen documentos por proyecto. Distribución: tarjetas por etapa y documento, datos compartidos antes de formularios específicos. Componentes: contexto autoritativo, campos con ayuda, filas repetidas, fechas, cifras COP, faltantes, guardado explícito, generación, versiones y descargas. Estilo: Material Design 3 coherente con la interfaz existente, verde institucional y fondos sólidos. Estados: vacío, consulta, confirmación y error recuperable.

La especificación es un artefacto de diseño. No registra una ejecución de Google Stitch.
