# Flujo del investigador

Abra el proyecto, entre a Expediente y seleccione Construir documentación. Revise el contexto del proyecto, complete los datos comunes y guárdelos. Abra el documento que corresponde a la etapa, bimestre o producto; complete sus campos y filas, revise los pendientes y guarde el borrador. Genere la versión editable, descárguela para verificar el contenido y gestione las firmas antes de radicar.

La revisión registra quién contrastó el contenido y sus observaciones. Los cambios posteriores vuelven anterior la versión generada. El ZIP reúne la última versión de cada documento y los adjuntos disponibles; conserva los faltantes. El historial permite descargar versiones anteriores.

Estados: campos vacíos con ayudas y acciones; consulta con indicador de carga; guardado y generación con confirmación accesible; error recuperable y conflicto de revisión con conservación de cambios locales.
