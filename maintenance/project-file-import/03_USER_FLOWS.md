# Recorrido y estados

- **Sin selección:** explicación breve, formatos y límites; control para elegir ZIP o archivos.
- **En proceso:** controles deshabilitados y estado accesible al analizar o guardar.
- **Análisis listo:** tarjetas por archivo con ruta, clasificación, datos propuestos y bimestre cuando corresponde; selección parcial y confirmación explícita.
- **Guardado:** resumen de originales nuevos, repetidos y campos completados; actualización del expediente y constructor.
- **Error:** detalle accionable y reintento conservando la selección.

Cambiar de proyecto descarta respuestas pendientes de la vista anterior. La selección ZIP conserva rutas; los archivos individuales permiten escoger carpeta y tipo.
