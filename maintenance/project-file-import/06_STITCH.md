# Referencia de interfaz

**Contexto:** área del investigador dentro del expediente existente.

**Distribución:** selección inicial, revisión de tarjetas y acción de registro; una columna en celular, controles distribuidos cuando hay espacio.

**Componentes:** botones del expediente, campos etiquetados, tarjetas por archivo, avisos, indicadores de proceso y estado de resultado.

**Estilo:** conservar el sistema visual institucional del expediente descrito en `DESIGN.md`.

**Estados:** sin archivos, analizando, revisión lista, guardando, éxito y error con reintento. La revisión debe conservar legibilidad de rutas largas y nombres extensos al 200 %.

Esta referencia documenta la implementación local; no acredita una ejecución en un servicio externo de diseño.
