# Diseño de importación de proyectos

## Lenguaje visual

El bloque de carga usa la identidad visual existente de SENNOVA: verde y esmeralda para las acciones, neutros claros para el contenido y ámbar o rojo solo para advertencias y errores.

## Reglas de interfaz

- Mantener título, ayuda y controles dentro de una tarjeta con espacio perimetral propio.
- Conservar botones y texto legibles en pantallas angostas.
- Usar foco visible, nombres accesibles y regiones `status` o `alert` para cambios de estado.
- Mostrar las extracciones como sugerencias que necesitan revisión humana.
- No añadir tokens globales nuevos para este bloque; reutilizar el sistema actual de utilidades Tailwind.
