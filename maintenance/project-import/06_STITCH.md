# Prompt de diseño para Stitch

## Contexto

Diseñar el bloque para cargar una formulación de proyecto CAP dentro del formulario de creación de SENNOVA CGAO. La persona usuaria es personal institucional y necesita revisar la información extraída antes de guardarla.

## Distribución

Ubicar el bloque en la pestaña **Básicos**, antes de los campos del proyecto. Mantenerlo a ancho completo, legible en móvil y coherente con el formulario actual.

## Componentes

Usar una zona para cargar DOCX, una etiqueta de campos detectados, la referencia al grupo o semillero cuando se encuentre, botones de reintento y retiro, y mensajes accesibles de estado.

## Estilo

Conservar los tonos esmeralda y verdes institucionales del sistema, bordes suaves, controles táctiles y contraste legible. No presentar las sugerencias como datos aprobados.

## Estados

Diseñar los estados vacío con CTA, lectura en curso con esqueleto, lectura exitosa con advertencia de revisión y error con reintento o selección de otro archivo.
