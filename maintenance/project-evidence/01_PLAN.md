# Plan del expediente documental

Resultado: doce grupos persistidos y disponibles desde el primer despliegue; cada proyecto cuenta con diagnóstico, carga y exportación de las seis carpetas solicitadas.

1. Datos: catálogo no destructivo; referencias válidas; migración opcional de bimestre.
2. Servicios: disponibilidad de archivos, informes por período, soportes de productos, ZIP y cierre atómico.
3. Interfaz: orientación por etapa, permisos, estados visibles y actualización sin cerrar el expediente.
4. Verificación: pruebas primero con fallos esperados, suites completas, PostgreSQL real, cobertura de funciones y compilación.

Se preservan los grupos, usuarios y documentos vigentes. No se importan hechos contradictorios del ejemplo ni se publican sus datos personales como plantillas.
